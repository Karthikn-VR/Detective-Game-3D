# Midnight Case: The Developer's Trail 🕵️‍♂️

A cinematic, 3D first-person investigation game , Built with React, Three.js, and Framer Motion.

## 🌟 The Experience
Step into the shoes of a detective investigating the digital workspace of Karthikeyan VR. Uncover 13 pieces of evidence—from system architectures to cloud certifications—to reveal the story of a developer who was "never lost, but still building himself."

## 🚀 Key Features
- **True First-Person Exploration**: Seamless movement and look controls using `PointerLockControls`.
- **Dynamic Flashlight System**: A realistic detective torch attached to the camera gazepoint.
- **Interactive Terminal**: A custom CRT hacking interface that fetches live repository data directly from the **GitHub API**.
- **Mobile Responsive**: Fully playable on mobile with virtual joystick navigation and "Tap-to-Walk" floor interaction.
- **Cinematic Narrative**: High-end intro sequence, environmental storytelling, and a memorable revelation ending.
- **Noir Aesthetic**: Gritty, moody lighting with film grain and vignette effects.

## 🛠 Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS
- **3D Engine**: React Three Fiber (Three.js)
- **Physics/Controls**: React Three Drei
- **Animations**: Framer Motion, GSAP
- **State Management**: Zustand
- **API**: GitHub REST API

## 🎮 Controls

### **Desktop**
- **W/A/S/D**: Move
- **Mouse**: Look around
- **SHIFT**: Sprint
- **C**: Crouch
- **E**: Interact with objects
- **F**: Toggle Flashlight
- **I / J**: Inventory / Journal
- **ESC**: Pause / Menu

### **Mobile**
- **Joystick**: Move
- **Tap Floor**: Auto-walk to position
- **Drag Screen**: Look around
- **E Button**: Interact
- **🔦 Button**: Toggle Flashlight

## 📦 Local Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/Karthikn-VR/Detective-Game-3D
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   ```

## 🌐 Deployment
This project is optimized for **Vercel**. 
- Simply connect your GitHub repository to Vercel.
- The `vercel.json` is pre-configured for SPA routing.
